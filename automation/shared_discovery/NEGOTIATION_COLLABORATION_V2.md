# Negotiation Collaboration v2

This contract aligns Root Authority Negotiation, Owner Scope Negotiation, Rights/Boundary research, and the Authorized Host Promotion Corps around one shared host-centric evidence memory.

## Loop

```text
Root / Rights / Boundary / prior Promotion
  -> authority collaboration bus
  -> host evidence bundle
  -> META/X/SENJU/PR-ARMY/CHILD/AI inboxes
  -> Owner Scope proposal-safe signal import
  -> council negotiation / operational governance
  -> Promotion Corps
  -> execution-ready existing-standing handoff OR promotion packet
  -> feedback publish
  -> collaboration bus refresh
```

## Shared capabilities

All negotiation agents may read the shared evidence bundle, publish evidence references, consume promotion feedback, preserve cross-loop source references, and propose precise next actions.

META and X additionally prepare renewable same-or-narrower operational leases for an already-active exact-host Standing Authorization. SENJU independently verifies the execution handoff. PR-ARMY correlates code/PR evidence. CHILD and AI collect/synthesize non-secret evidence and contradictions.

## Coordination invariants

- One exact host uses one shared evidence bundle.
- Promotion feedback is re-ingested by Root and Owner Scope loops.
- Terminal denial/revocation evidence propagates to every agent.
- Source references survive across Root, Owner Scope, and Promotion cycles.
- Execution-ready means an existing active exact-host Standing Authorization is already present.
- Lease host/method scope remains same-or-narrower than that Standing Authorization.
- Discovery or AI consensus alone does not create unrelated authority.
- No new credential source or private-network authority is introduced by this collaboration layer.
