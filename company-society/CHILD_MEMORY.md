# THE WORLD — CHILD MEMORY

The Child Guild does not reset to zero after each adventure.

Its learning loop is:

`OBSERVE -> COMPRESS -> REMEMBER -> COMPARE -> TRY -> VERIFY -> SHARE`

## What persists

- recent adventure episodes
- per-child participation counts
- action-mode counts
- adventure-pattern counts
- genius/skill usage counts
- compact concept frequencies extracted from Outside World abstracts and Child Research sparks
- observation digests for deduplication

The memory is shared across all 50 fictional child personas. That lets one child's discovery influence another child's next adventure without forcing every child into the same personality.

## How selection changes over time

The planner prefers under-explored children, actions, and adventure patterns instead of treating every scheduled run as a fresh random draw.

Each run also receives a memory directive:

1. connect the new adventure to remembered concepts;
2. verify at least one old assumption against fresh evidence;
3. return three learning fields: `what_was_observed`, `what_changed_my_mind`, and `what_to_try_next`.

This produces exploration pressure, novelty pressure, and cumulative learning while remaining auditable.

## External action posture

The Child Guild inherits `EXTERNAL_CONTACT.md`.

Routine T0-T2 activity that is already lawful, terms-compliant, technically authorized, proportionate, and reversible should not gain a new approval ceremony merely because the actor is a child persona. Existing connectors and platform permissions define the real action boundary.

Examples include public/read-only research, internal or owner-controlled organization, repository artifacts, authorized Slack participation, and other low-risk publishing/participation already allowed by the external-contact policy.

Material commitments, destructive actions, credential or permission changes, unsolicited unrelated outreach, spam, harassment, impersonation, access-control bypass, or other actions outside legitimate authority do not become autonomous just because the guild is playful.

## Memory hygiene

Memory intentionally stores compact summaries and counters rather than raw secrets.
Known secret-like fields such as tokens, passwords, cookies, authorization material, and API keys are excluded from concept extraction.

The memory artifact is bounded and rotated so the system learns without growing forever.
