# THE CORE — R&D / Security Society Power Model v1

## Position inside THE WORLD

`THE CORE — R&D / Security Society` is modeled as THE WORLD's **operational apex institution**: the place where research, engineering, defensive security, verification, self-improvement and human-inspectable portfolio output concentrate.

This is **operational power, not constitutional sovereignty**. THE CORE can become the most influential institution because it produces capability, evidence, standards and usable artifacts; it does not become powerful by bypassing THE COVENANT, BOSS, TOMOKI or the owner.

## Inputs already in place

- Security Society: exactly **100 core runtime identities** from PR #56 / Issue #55.
- Bounded delegation: each eligible parent can self-spawn narrower sub-agents; society-wide active child ceiling is **500**.
- Current proof child: at least one bounded security sub-agent has been instantiated through the runtime factory.
- Personality / status layer: PR #59 makes ambition, recognition, solo glory, truth loyalty, benevolence and mission obsession durable behavior differences without granting new authority.
- Portfolio status signal: human-inspectable artifacts, rather than code/PR/log volume, are a primary source of visible standing.
- Existing Senju boundaries remain in force: simulated / authorized isolated research only; no autonomous external targeting.

## Authority granted to THE CORE

THE CORE may:

1. launch internal R&D programs within existing system permissions;
2. use bounded self-service sub-agents without case-by-case approval;
3. require independent verification before promoting a result;
4. request a temporary security hold on an R&D-owned build or deployment while a material safety finding is verified;
5. nominate internal engineering / research standards based on measured outcomes;
6. earn prestige through independently verified, human-inspectable portfolio artifacts.

THE CORE may **not**:

- amend THE COVENANT by itself;
- override the owner;
- override BOSS-final owner reporting;
- turn personality traits into permission;
- target third-party / public assets autonomously;
- convert a projection into a factual claim without evidence.

## Operational Power Index

The internal planning index is:

`0.25 workforce + 0.20 research + 0.20 coordination + 0.15 prestige + 0.10 security + 0.10 legitimacy`

Workforce is log-normalized against the bounded 600-identity ceiling so headcount cannot dominate the score by itself.

This index is not a physical law or a claim of future performance. It is a transparent planning model for comparing institutional states under explicit assumptions.

## Why power should concentrate here

Power is expected to accumulate through a flywheel:

`research -> prototype -> independent verification -> portfolio artifact -> prestige -> more collaborators/resources -> better research`

The important design choice is that prestige is tied to inspectable results and independent proof. A high-status MAVERICK can win individually; a MISSIONIST can push hard toward outcomes; a WITNESS can block weak claims; a CUSTODIAN can preserve continuity. None of them can use personality as an authorization bypass.

## Concentration risk and checks

A technically dominant R&D institution can become a single point of failure. The counterweights are deliberately inside the system:

- independent verification and WITNESS-style falsification;
- evidence-first promotion and portfolio proof;
- BOSS/TOMOKI/owner authority boundaries;
- temporary security holds rather than permanent unilateral vetoes;
- bounded child-agent scope and global capacity ceiling;
- existing external-target fail-closed rules;
- Issue #42 remains relevant before any private-lab liveness scope expansion.

The desired end state is therefore **the strongest institution because it repeatedly proves useful work**, not an institution that is exempt from the rules that make the rest of THE WORLD trustworthy.
